# E-Commerce Sales & Profit Tableau Dashboard

## Project Overview

This project presents an interactive Tableau dashboard for analyzing e-commerce sales, profit, and profitability.

The dashboard helps understand:
- Sales performance by product category
- Profit performance by category
- Monthly sales trends
- Profitability across categories

## Dashboard Preview

![E-Commerce Sales & Profit Dashboard](dashboard.png)

## Key Insights

- Compared sales performance across different product categories.
- Analyzed profit contribution by category.
- Studied monthly sales trends to understand business performance over time.
- Compared profitability using Profit Ratio.
- The dashboard provides a simple visual view of overall e-commerce performance.

## Tools Used

- Tableau Desktop
- Tableau
- GitHub
- Sample Superstore Dataset

## Dashboard Components

The dashboard contains:

1. **Sales by Category** – compares total sales across categories.
2. **Profit by Category** – compares total profit across categories.
3. **Sales Trend** – shows monthly sales performance over time.
4. **Profit Ratio by Category** – compares profitability across categories.

## How to Open the Project

1. Download the `.twbx` Tableau workbook from this repository.
2. Open the file using Tableau Desktop.
3. Open the **E-Commerce Sales & Profit Dashboard** worksheet.
